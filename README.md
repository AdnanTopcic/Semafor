# Traffic Light Simulation

A simple traffic light simulation created using Flowcode.

## Description

This project simulates the operation of a standard traffic light system. The lights change in the following sequence:

1. Red
2. Red and Yellow
3. Green
4. Yellow
5. Red

The simulation demonstrates basic programming logic, timing, and sequence control in Flowcode.

## Software Used

- Flowcode

## Features

- Automatic light sequence
- Realistic traffic light behavior
- Educational demonstration of control flow
